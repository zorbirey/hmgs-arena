# HMGS ARENA Product Rules

## Test feedback

- During a test or mock exam, the user is never shown whether an answer is correct or incorrect immediately after selecting it.
- No green/red correctness feedback, explanation, score change, or correctness message is shown between questions.
- The selected answer is shown only as a neutral selection and saved.
- Question explanations are shown only after the test has ended.

## Results flow

- Free users: test ends -> interstitial ad -> results screen.
- Premium/reklamsız users: test ends -> results screen directly.
- Results include correct, incorrect and blank counts, score/XP where applicable.
- Incorrect questions are not presented as one long scrolling list. The user opens a dedicated review flow and inspects one wrong question per screen/page.
- Wrong-question review shows the user's answer, the correct answer, and the explanation/source.

## Single-screen UX rule

- Primary app screens are designed to fit inside one device viewport without vertical scrolling.
- Home/Arena, quiz, results, ranking and core navigation must remain usable without dragging the page up or down.
- When content cannot reasonably fit on one screen, split it into tabs, cards or paged views instead of creating a long scrolling page.
- The home screen prioritizes only the information needed at a glance: daily target, streak, XP, continue, Arena, full mock, weak topic and personal ranking.
- Ranking screens show a compact relevant slice rather than an endlessly scrolling leaderboard.
- Opening splash and Inspired From Zeus screens scale to the device viewport without cropping important artwork.

## UX principle

The question-solving phase should feel calm and uninterrupted. Evaluation is intentionally deferred until the end of the test to reduce stress and avoid pushing the user out of the study flow. The app should feel like a focused mobile interface rather than a web page that requires continuous scrolling.
